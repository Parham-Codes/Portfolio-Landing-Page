# 🌐 Portfolio Website

A modern and responsive portfolio website built with **React** and **Vite**. This project demonstrates a clean component-based architecture and a simple, elegant user interface suitable for showcasing personal information, services, and blog posts.

---

## ✨ Features

- Responsive landing page
- Clean and modern UI
- Component-based architecture
- About section
- Services section
- Blog section
- Smooth navigation between sections
- Easy to customize and extend

---

## 🛠️ Built With

- React 19
- Vite
- JavaScript (ES6+)
- CSS3
- HTML5

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Parham-Codes/REPOSITORY_NAME.git
```

Go to the project directory:

```bash
cd REPOSITORY_NAME
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
